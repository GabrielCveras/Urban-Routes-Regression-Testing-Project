# Urban-Routes-Regression-Testing-Project

Projeto de Quality Assurance (QA) realizado durante minha formação em testes de software, com foco em testes de regressão de uma aplicação Web.

O objetivo do projeto foi executar os casos de teste fornecidos para o Urban Routes, comparar os resultados obtidos com os resultados esperados e documentar possíveis falhas.

## 🎯 Objetivos do Projeto

Executar casos de teste de regressão.

Validar funcionalidades da aplicação com base nos resultados esperados.

Identificar diferenças entre o comportamento esperado e o comportamento real.

Registrar o status de cada caso de teste.

Documentar bugs encontrados durante a execução.

Associar os relatórios de bugs aos casos de teste reprovados.

## 🌐 Testes Web

O Urban Routes é uma aplicação Web que calcula rotas, tempo e custo de viagem com base nos endereços de origem e destino informados pelo usuário.

## Funcionalidades abordadas no projeto:

Campos para informar os endereços de origem e destino.

Modos de viagem: Optimal, Flash e Personal.

Opções de transporte: carro próprio, caminhada, táxi, bicicleta, scooter e compartilhamento de carro.

Cálculo do tempo e do custo estimado da viagem.

## Atividades realizadas:

Execução dos casos de teste fornecidos pela equipe de QA.

Verificação das pré-condições e etapas descritas nos casos de teste.

Comparação dos resultados reais com os resultados esperados.

Registro do status de cada caso como Aprovado ou Reprovado.

Criação de relatórios para os bugs encontrados.

Associação dos IDs dos bugs aos casos de teste reprovados.
